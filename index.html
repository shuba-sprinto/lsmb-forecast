How this forecast is calculated

Closed won (QTD) = deals in CW : Closed Won / Close Won with a Close Date between 2026-05-01 and 2026-07-31 inclusive (filtered as < 2026-08-01 to avoid dropping same-day late closes that carry a time component — the same bug fixed in W9).

HOT (late-stage) = open deals in Negotiating, Pricing, or Negotiating & Contracting, or Solutioning-Closed stages. These are counted in both worst and best case. Note: "S2 : Evaluation Initiation" was previously grouped here on the "S2" prefix alone — corrected this pass, since the stage name signals the start of an evaluation, not a closing signal, so it now sits in WARM.

WARM (mid-stage) = open deals in Discovery/Validating/Qualifying, Deep Discovery, Solutioning-Started, Custom Demo, or Evaluation Initiation stages. Counted in best case only.

Excluded = Lead Identification and Use Case Identification stage deals (too early to forecast), plus Nurture, Closed Lost, Unfit, and Demo No-Show across both cases.

Worst case = Closed won + HOT. Best case = Closed won + HOT + WARM.

Stale/overdue flag = any open deal (not Won/Lost/Nurture/Unfit) whose Close Date is already before today (2026-07-23). These stay in the worst/best case totals at face value but are surfaced separately since a blown close date is a weaker signal than the stage label alone implies — 17 deals / $130,866 this week, concentrated in Aditya's and Anirudh's books.
